Behind the workbench

Reliable decisions, made explicit.

Python + SQLite

The original batch tool reads CSV submissions and reference tables, checks all applicable rules, normalises valid rows and produces clean.csv and errors.csv. It uses the Python standard library.

Explainable classification

Keyword rules map free-text categories to a single category. Ambiguous and unmatched values are rejected for review. The implemented classifier uses deterministic rules.

Deterministic deduplication

Normalised merchant names form groups. The newest registration date wins; the smallest submission ID breaks ties. Matching on name alone can merge separate branches.

Scope and engineering limitations

This browser experience replays prepared validation results and recomputes duplicate groups for selected partners. It does not execute Python. Demo identifiers, merchant names, contacts and routing addresses are fictional.

The original implementation loads canonical categories from SQLite but does not enforce that membership during classification; the prepared demo outputs have been checked against the category reference. Broader phone validation, transactional outputs, concurrency control and production-scale benchmarks remain future improvements. The fixed validation date is 1 June 2026.
